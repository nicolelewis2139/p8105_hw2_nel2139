This dataset contains information about the NYC subway system including
the subway `line`, `station_name`, `station_latitude`,
`station_longitude`, the routes served at each station (stored across
`route1` through `route11`), the `entrance_type`, whether `entry` is
allowed, whether there is `vending`, and whether the station is `ada`
compliant. To clean the data, I imported the CSV file using a relative
path and treated blank cells as missing. Since `route1` through `route7`
mostly listed letter trains like the A and N trains, they were treated
as character variables in R. However, `route8` through `route11` only
consisted of numbered trains like the 1 train so they were treated as
numeric (dbl) in R. To ensure consistency, I reclassified `route8`
through `route11` from numeric (double) to character variables, so that
all route columns are the same type. I then cleaned the variable names,
kept only the variables listed above, and converted `entry` from a
character variable with YES/NO values to a logical variable with
TRUE/FALSE values. The dataset has 1868 rows and 19 columns. These data
are not tidy because route is a single variable spread across 11
columns. In tidy data, each variable should have its own column, so the
routes should instead be stored in one column, with a separate row for
each route served.

The baseline data were imported with `read_csv()`. The first row of the
datafile contains descriptions of each variable, so `skip = 1` was used
to ensure this section was not included in the imported data, and that

recoded to NA, which ensured that `age_at_onset` was treated as a
numeric variable, rather than a character variable. Variable names were
then cleaned and converted to snake case. Sex and APOE4 status were
originally coded as 0 and 1 and therefore treated as numeric in R. Since
these are categorical variables, they were recoded with `case_match()`
as male/female and carrier/non-carrier, respectively, and converted to
factor variables with `as.factor()`. Finally, `filter()` was used to
remove participants who did not meet the inclusion criteria of no MCI at
baseline. Participants whose `age_at_onset` was at or before their
baseline `current_age` already had MCI at baseline and were removed
(n=4), while participants with no age at onset were kept because they
met the inclusion criteria; they were MCI-free at baseline and simply
did not develop MCI during follow-up. Participants who did not develop
MCI have `NA` for `age_at_onset`. This dataset contains demographic
information for 479 participants measured at the study baseline and
includes 6 variables: `id`, `current_age`, `sex`, years of `education`,
`apoe4` carrier status, and `age_at_onset` of MCI. While the other
variables were measured at baseline, `age_at_onset` was recorded during

The amyloid dataset was imported with `read_csv()`. Like the baseline
data, the first row of the datafile contains a description of the
variables, so `skip = 1` was used to ensure this row was not included in
the imported data, and that the second row was used as the column names.
Missing amyloid ratio values were recorded as `NA` and `Na` in the data
file, so `na = c("NA", "Na", "")` was used to read all of them as
missing and ensure the amyloid ratios were classified as numeric.
Variable names were then cleaned and converted to snake case and
`study_id` was renamed to `id` to match the baseline dataset. The data
were originally in wide format, with a separate column for the amyloid
ratio at each time point. So, `pivot_longer` was used to convert the
data into long format; the five time point columns were stacked into two
columns, `years_since_baseline`, which records the time point, and
`amyloid_ratio`, which records the measured ratio value. The time point
variable was named `years_since_baseline` and treated as numeric because
the description row of the datafile states that each time point is
measured in years elapsed since the study baseline, which represents an
amount of time which has numeric meaning. This label makes it clearer
what the values represent. Then, the time point values were cleaned by
removing the “time\_” prefix, replacing “baseline” with 0, and
converting the variable to numeric so that the `years_since_baseline`
has values of 0, 2, 4, 6, and 8. This dataset contains 487 participants
and 2435 rows (one per participant per time point), with 3 variables.
The variables included in this dataset are: `id`,
`years_since_baseline`, and `amyloid_ratio`. The `amyloid_ratio`
variable records the amyloid β 42/40 ratio, a biomarker that changes
over time and has been linked to the manifestation of clinical symptoms
of Alzheimer’s disease. For each participant, this ratio is recorded at
baseline and at 2, 4, 6, and 8 years after baseline. However, there are
172 missing amyloid ratio values in total, and 147 of participants have
at least one missing time point.
